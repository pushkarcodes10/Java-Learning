## Compile and Run

Compile and run a standalone Java program from the repository root:

```powershell
javac "Hello.java"
java Hello
```

To compile and run a program in another directory:

```powershell
javac "Semester-3/Main.java"
java -cp "Semester-3" Main
```

For files containing a `main` method, replace the file and class names as needed.

```powershell
javac "Java Lab/SimpleCalculator.java"
java -cp "Java Lab" SimpleCalculator
```
